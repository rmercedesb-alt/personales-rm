Administración de Inmuebles





La finalidad del sistema es crear los procesos, esquemas y sistemas necesarios para que la empresa administradora pueda llevar a cabo el proceso de administrar inmuebles en diferentes modalidades.



Es importante que el sistema maneje los siguientes módulos:



* Menu Principal
* Mantenimientos
* Ingreso de inquilinos
* Procesos
* Cuentas por Cobrar
* Reportes
* DashBoard
* Usuarios  





Detalles de los modulos:



Menu Principal es la pantalla o plataforma donde se alojan todos los modulos del sistema, que se describieron anteriormente y el fonde preferiblemente debe ser de manera subliminar un edificio de condominio (Que trae por defecto) y que el administrador podría cambiar el fondo de esta pantalla en cualquier momento utilizando una foto de su galería, para ello el sistema debe proporcionar la opción de como hacerlo.  En el este entorno debe aparecer los dash mas importante de cada modulo y que sed configuren al momento de crear el dash en una opción que diga DashBoard principal.
